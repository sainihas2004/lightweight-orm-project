# Lightweight ORM 🚀

A lightweight TypeScript ORM designed for PostgreSQL-compatible databases.

This project demonstrates how to build a custom ORM package and use it inside a full-stack Todo application.

## ✨ Features

- Lightweight and simple ORM
- Built with TypeScript
- PostgreSQL-compatible database support
- Model and schema definitions
- Database querying support
- Published as an npm package
- Full-stack Todo application example
- React frontend
- Node.js and Express backend
